# gaugepack

Gauge color pack values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/gaugepack/

## Install / run

```bash
git clone https://github.com/theworker02/gaugepack.git
cd gaugepack
node src/cli.js
node --test
```
